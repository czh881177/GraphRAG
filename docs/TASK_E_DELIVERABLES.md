## 三、如何运行 / 复现

### 1. 启动知识图谱（前置条件）

```powershell
.\start_neo4j.ps1        # 启动 Neo4j（Docker）
.\build_kg_dyn.ps1       # 首次运行建图（语料 → 抽取 → 入库）
```

### 2. 启动后端 API

```powershell
.\.venv\Scripts\python.exe -m backend.api   # 监听 http://localhost:5000
```

### 3. 打开前端页面

直接用浏览器打开 `index.html`（或部署到任意静态服务器）。页面内：
- 输入问题 → 选择检索模式 → 点「提问」
- 右侧图谱区域展示对应知识图谱（graph.html）

### 4. 重新生成图谱可视化（可选）

```powershell
.\generate_visualization.ps1
```
