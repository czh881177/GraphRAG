# 医药数据方案（DATA_PLAN）v1.0

> 制定：组长 A · 执行：B（数据/图谱）· 生效：2026/9/7
> 目标：两周内构建**实体 ≥ 300、关系 ≥ 500** 的医药知识图谱，支撑第一周汇报 demo 与最终答辩。

## 1. 数据来源（公开、无需版权授权）

| 来源类型 | 示例 | 用途 |
|---|---|---|
| 药品说明书（公开） | 常见 OTC/处方药说明书文本 | 药物、适应症、不良反应、生产公司 |
| 健康科普文章 | 公开科普站点的疾病/用药科普 | 疾病、症状、作用机制 |
| 医学知识页 | 公开的疾病/药物条目 | 补充实体与关系 |

> 建议优先选用**公开科普/公开说明类文本**（20–40 篇），规避版权与医疗建议合规风险。
> 本项目为技术演示，语料仅用于构建图谱与问答演示，不构成任何医疗建议。

## 2. 语料规模与目标

| 指标 | 目标值 | 说明 |
|---|---|---|
| 原始语料 | 20–40 篇 | 存入 `data/raw/` |
| 文本分块 | 每块 500–800 字 | 重叠 50–100 字，存 `data/processed/` |
| 实体总数 | ≥ 300 | 覆盖 6 类本体 |
| 关系总数 | ≥ 500 | 含实体间自定义关系 |
| 单块抽取质检 | 合格率 ≥ 80% | 人工抽检（B 把关） |

## 3. 目录约定（组长制定）

```
data/
├── raw/        # 原始语料：*.txt（每篇一个文件，UTF-8 / GBK 均可，脚本兼容）
└── processed/  # 清洗+分块后的语料：chunks.json / chunks_*.json
```

- 原始语料**不提交 Git**（`.gitignore` 已忽略 `data/raw/` 与 `data/processed/`）。
- 分块格式（供 build 脚本消费）：

```json
[
  { "index": 0, "source": "aspirin.txt", "text": "……" },
  { "index": 1, "source": "aspirin.txt", "text": "……" }
]
```

## 4. 本体类型表（6 类，Schema 与色板统一）

| 类型 | 含义 | 示例 | 前端色板 |
|---|---|---|---|
| 药物 | 药品/活性成分 | 阿司匹林、布洛芬 | #f72585 |
| 疾病 | 疾病/适应症 | 偏头痛、类风湿关节炎 | #7209b7 |
| 症状 | 症状/不良反应表现 | 头痛、发热 | #f77f00 |
| 公司 | 药企/研发机构 | 拜耳公司 | #06ffa5 |
| 作用机制 | 靶点/机制 | 环氧合酶、前列腺素合成 | #3a0ca3 |
| 副作用 | 不良反应 | 胃肠道出血、恶心 | #f77f00 |

> 抽取时实体类型**收敛到这 6 类**（+必要时 `概念`），超出类型由抽取 Prompt 归并，避免图谱碎片化。

## 5. 关系类型建议（自定义，抽取 Prompt 约束）

| 关系 | 方向 | 示例 |
|---|---|---|
| `研发` | 公司 → 药物 | 拜耳公司 -研发-> 阿司匹林 |
| `作用于` | 药物 → 作用机制 | 阿司匹林 -作用于-> 环氧合酶 |
| `治疗` | 药物 → 疾病 | 阿司匹林 -治疗-> 头痛 |
| `缓解` | 药物 → 症状 | 布洛芬 -缓解-> 发热 |
| `副作用` | 药物 → 副作用 | 布洛芬 -副作用-> 胃肠道不适 |
| `属于` | 药物 → 药物 | 布洛芬缓释胶囊 -属于-> 布洛芬 |

## 6. 质检标准（B 执行）

- 抽检 20 个分块：实体名无错别字、类型归属正确、关系方向正确、无重复/孤儿实体；
- 建图后运行计数核对：`MATCH (n) RETURN labels(n)[0] AS t, count(n)`；
- 检查孤立节点（无任何关系的实体）比例 ≤ 5%。
