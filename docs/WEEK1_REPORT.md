## 汇报结构（20 min）

### 1. 背景与目标（5 min · A）
- 问题：传统向量 RAG 无法回答跨实体多跳问题（例："哪些药物通过抑制环氧合酶发挥作用？"）
- 方案：知识图谱（Neo4j）+ 向量检索 + LLM 生成 = GraphRAG
- 目标：医药领域图谱问答系统；两周交付

### 2. 系统架构（5 min · A）
- 四层架构图：前端（D3 可视化）→ Flask API → 检索/生成（graphragexpr）→ Neo4j + DeepSeek
- 数据流：语料 → 分块 → LLM 抽取实体关系 → 建图 + 向量/全文索引 → 检索 → 生成
- 展示 `docs/API_CONTRACT.md` 与 `docs/SCHEMA.md`（契约先行）

### 3. 现场 Demo（5 min · C / E）—— 本周红线
- **E 展示**：前端知识图谱可视化（按类型着色、缩放），讲解节点/关系/索引
- **C 演示**：命令行跑通 3–5 个预置医药问题（至少 1 个多跳）：
  - "阿司匹林和布洛芬有什么共同点和区别？"
  - "哪些药物通过抑制环氧合酶发挥作用？"
  - "布洛芬适用于哪些疾病、有哪些副作用？"
- **B 展示**：图谱统计（实体数 / 关系数 / 类型分布表）

### 4. 本周进展与下周计划（5 min · A）
- 本周成果清单（按 A–E 逐人一句话）
- 遇到的问题与风险（API 限速 / 抽取质量 / 环境）
- 下周计划：Web 集成 → 评估 → 测试 → 答辩
